全自动血小板聚集分析系统
软件可运行环境说明

Coagulation.exe V1.0.1.0 KS-600 / KS-800 / KS-1200
用途：供医院信息科、装机工程师确认上位机电脑能否运行本软件
编制日期：2026-09-01

Windows 7 64 位可以运行。本软件用 Qt 5.10.0 + MSVC 2015 x64 编译，Qt 官方支持 Windows 7（x64）+ MSVC 2015。 Windows 7 32 位不能运行。必须先装 SP1、通用 C 运行库补丁和 VC++ 2015 x64 运行库，摄像头/串口驱动也要是 Win7 版。日常交付仍建议 Windows 10 64 位。
本软件是仪器配套的 Windows 64 位上位机，安装在与分析仪相连的工控机或专用电脑上。不支持手机、平板、macOS、Linux，也不支持任何 32 位 Windows。

1. 操作系统

推荐Windows 10 64 位（1809 及以上）。开发与出厂验证环境为此系统。
可用Windows 7 SP1 64 位、Windows 8.1 64 位、Windows 11 64 位。Win7 / Win11 需按第 2 节补齐运行库并现场验证串口、摄像头、打印。
不可用Windows 7 / 10 / 11 的 32 位；无 SP1 的 Windows 7；Windows XP / Vista；macOS；Linux。
系统架构必须 64 位 (x64)。
语言中文 Windows。区域建议「中国」。
权限首次装驱动建议管理员。日常运行要求对软件安装目录有读写权限（数据库、日志、图片都写在程序目录）。

2. Windows 7 64 位专项说明

结论：可以运行，不是“开箱即用”。请按下面清单装机。

检查项 要求
版本 必须是 Windows 7 旗舰版 / 专业版 64 位，并已安装 Service Pack 1。开始菜单 → 计算机 → 属性，看“系统类型”是否为 64 位。
系统补丁 安装微软 KB2999226（Universal CRT / 通用 C 运行时）。未打此补丁时，双击 exe 常提示“无法启动此程序，因为计算机中丢失 api-ms-win-crt-runtime-l1-1-0.dll”。也可直接安装较新的 Visual C++ 2015–2022 可再发行组件包（x64），一般会带上该运行时。
VC++ 运行库 必须安装 Visual C++ 2015 可再发行组件包 x64（或 2015–2022 x64 合并包）。缺 msvcp140.dll / vcruntime140.dll 无法启动。
驱动 USB 转串口、测高摄像头、扫码枪必须有 Windows 7 64 位驱动。只有 Win10 驱动、在 Win7 上装不上的，软件界面能开、仪器也连不上。
电源与 USB 关闭“USB 选择性暂停”；不要让系统睡眠。工控机建议接 UPS。
未验证点 当前出厂验证在 Windows 10 64 位上完成。Win7 现场需确认：能进登录界面、COM 口通信、测高拍照、打印 A5 报告。
Windows 7 已停止官方安全更新。医院若信息科强制要求 Win7，可以装机，但建议尽快迁到 Windows 10 64 位。Win7 上杀毒软件、旧驱动更容易误拦 DLL 或串口。

4. 必须安装的运行库

出厂安装包一般已带齐。若只拷贝了 exe，或缺 DLL 无法启动，需具备：

VC++ 2015 x64vcruntime140.dll、msvcp140.dll。Win7 上请用官方安装包安装，不要只拷这两个文件。
Qt 5.10.0（MSVC2015_64）与程序一起部署：platforms\qwindows.dll、sqldrivers\qsqlite.dll、imageformats、mediaservice（摄像头）等。
OpenCVopencv_world453.dll；测高分层另需 opencv_world3416.dll（两套可同目录并存）。
配套 DLLbloodlayer.dll、UsbCodeDispose.dll、suoweidll.dll、QZXing3.dll、QsLog 等须与 exe 同目录。

5. 与仪器相关的硬件条件

分析仪主机KS-600 / KS-800 / KS-1200，通信线正常，上位机机型与实机一致。
串口设备管理器能看到 COM 口。同一 COM 口不能被其他软件占用。
测高摄像头DirectShow 能识别。被会议软件占用时测高会失败。
USB 扫码枪按仪器配置接入。
耗材刷卡RFID 在仪器主板，电脑只需串口畅通。
打印机（可选）Windows 能打印即可。报告按 A5、300 dpi 排版。

6. 软件会写入的本机目录

以下路径都在程序安装目录下，必须可写。数据是本地 SQLite，不需要 MySQL / SQL Server。

路径用途
SQLFile\SWData.db 等患者、结果、耗材数据库
suoweiLogFile\运行日志，单文件最大约 512 MB
CurveImages\、TestResults\曲线图、检测结果
FindHighImage\测高拍照缓存
plugins\Qt 插件，启动加载
  • 同一台电脑只能运行一份本软件。
  • 不要放在只读光盘或无写权限的网盘映射盘。

7. 网络与 LIS

单机不接医院网也可以检测、出报告、存本地库。
LIS 对接软件带 HTTP 接口（示例端口 8080）。启用后需固定 IP，防火墙放行，LIS 与本机网络可达。
曲线共享若 LIS 用网上邻居取图，需共享 CurveImages 并授权读取。

8. 现场检查清单

  • 计算机属性：64 位操作系统。Win7 须为 SP1。
  • 显示：1920×1080，缩放 100%。
  • 双击 Coagulation.exe 能进登录界面，无“缺少 dll / 无法定位程序输入点”。
  • 设备管理器：COM 口、摄像头、打印机无感叹号。
  • 杀毒软件将安装目录加白名单。
  • 关闭睡眠和 USB 选择性暂停。
  • 登录后机型与实机一致，通信正常后再做样本。

9. 不能运行或效果差的情况

  • 32 位 Windows（含 Windows 7 32 位）。
  • Windows 7 未装 SP1，或未装 KB2999226 / VC++ 2015 x64。
  • 虚拟机未直通 USB/串口；远程桌面使用摄像头。
  • 压缩包未解压直接运行；安装目录只读。
  • 同时开两份本软件；COM 口或摄像头被占用。
  • 显示缩放不是 100%；分辨率低于 1366×768。
