血小板聚集仪 LIS 连接说明书

仪器只认一套固定结果。医院来取结果，或仪器按通用 HL7、ASTM 主动发给 LIS。换一家医院时，改地址、端口和协议即可，不用改检验程序。

1. 在仪器上打开

  1. 进入仪器参数设置，左侧点 LIS。
  2. 勾选 启用 LIS，再按医院的接法勾选下面两项里需要的那些。
  3. 点 保存并应用。不保存就不会监听，也不会发送。
  4. 默认是关闭的。未保存前，仪器不会占用端口。
设置作用
允许医院来取结果仪器在本机开一个 HTTP 端口，LIS 或中间件来查询。
取数端口默认 8080。防火墙要允许这个端口的入站访问。
主动发给 LIS结果出来后，仪器去连接医院的 IP 和端口。
测试完成后发送该样本的试剂都结束后发送。
审核后发送审核医生写入后发送。两项都勾选时，等审核后再发，避免先发出一份没有审核人的结果。
协议HL7 或 ASTM。用医院 LIS 厂家指定的那一种。
LIS 地址 / 端口医院服务器的 IPv4。HL7 常用 2575，ASTM 常用 5000，以医院实际端口为准。
编码默认 UTF-8。对方要求国标中文时选 GBK。
发送方 / 接收方写进消息头，方便 LIS 识别这台仪器。可按医院要求改名称，字段位置不变。
测试网络只检查能不能连上对方端口，不发送病人结果。
重发选中下方列表里选一条，再发一次。

质控数据不会进入这条发送队列。

2. 医院来取结果

保存并应用后，页面上的取数地址类似：

http://仪器IP:8080/v1/health

LIS 使用 HTTP GET，返回 JSON，编码 UTF-8。

地址说明
GET /v1/health仪器在线时返回 status=ok。
GET /v1/config本机地址、曲线图前缀、图片保留天数。
GET /v1/samples?start_date=2026-10-01&end_date=2026-10-27按样本日期取列表。日期用 YYYY-MM-DD。
GET /v1/sample/{样本号}一条完整结果。样本号与仪器结果库一致，复查样本末尾可能带 F。
GET /v1/sample/{样本号}/curvesAA、ADP、EPI、COL、RIS 的曲线点，数值已按百分比。
GET /v1/sample/{样本号}/curves.png曲线图。

单条结果里常用字段：

JSON含义
sample_id样本号
barcode条码
patient_name / gender / age姓名、性别、年龄
department / bed_number / diagnosis科别、床号、临床诊断
referring_doctor / examining_doctor / review_doctor送检医生、检验医生、审核医生
results.AA 等原始结果串，顺序为 60 秒、180 秒、终点、最大聚集率，带百分号
max_aggregation_rate从结果串最后一段取出的最大聚集率
analysis_parametersAUC、MaxSlope、TMA、Lag、Adhesion
来取这种方式由医院或中间件按上面的地址读取。仪器软件不用为每家医院改接口。

3. 主动发送：HL7

协议选 HL7 时，仪器作为客户端连接 LIS，发送一条 ORU^R01，外面包 MLLP：以 0x0B 开始，以 0x1C 0x0D 结束。版本 2.5。

LIS 需回 ACK，其中包含 MSA|AA 或 MSA|CA。没有应答或应答为 AE、AR 时，仪器记失败并稍后重试。

MSH|^~\&|KS|SW|LIS|HOSPITAL|20261027223000||ORU^R01|样本号20261027223000|P|2.5|||||||UTF-8
PID|1||条码^^^^BAR||姓名|||M
OBR|1||样本号|PLT^Platelet Aggregation|||20261027223000
OBX|1|NM|AA_60^AA_60||35.20|%|||||F
OBX|2|NM|AA_180^AA_180||58.10|%|||||F
OBX|3|NM|AA_END^AA_END||60.00|%|||||F
OBX|4|NM|AA_MAX^AA_MAX||72.40|%|||||F
NTE|1||dept=血液科;referring=张三;examining=李四;review=王五;diagnosis=待查

ADP、EPI、COL、RIS 使用同样的后缀。有数值时还会带 AA_AUC、AA_MaxSlope、AA_TMA、AA_Lag、AA_Adhesion。年龄在 AGE，单位 yr。没有做出结果的试剂不会出现。

发送方、接收方、编码与设置页一致。MSH-18 为 UTF-8 或 GBK。

4. 主动发送：ASTM

协议选 ASTM 时，按 LIS2-A2 会话：仪器发 ENQ(0x05)，等待 ACK(0x06)，再逐帧发送，每帧等待 ACK，最后发 EOT(0x04)。帧格式为 STX + 帧号 + 记录 + CR + ETX + 两字节校验 + CR LF。校验是帧号到 ETX 的字节和，模 256，十六进制大写。

对方回 NAK 时，这一帧会再发一次。

H|\^&|||KS|||||||P|LIS2-A2|20261027223000
P|1||条码||姓名|||M
O|1|样本号||^^^PLT|R||20261027223000
R|1|^^^AA_60|35.20|%||||F
R|2|^^^AA_180|58.10|%||||F
R|3|^^^AA_END|60.00|%||||F
R|4|^^^AA_MAX|72.40|%||||F
C|1|L|dept=血液科;referring=张三;examining=李四;review=王五|G
L|1|N

项目代码与 HL7 的 OBX-3 相同。性别：男 M，女 F，其他 U。

5. 失败以后

发送记录在设置页下方。状态有待发送、发送中、已送达、失败。默认每 5 秒尝试一条，次数用尽后变为失败。选中该行点重发，会重新排队。

LIS 地址为空、样本还没有结果、网络不通，都会记在说明列。

6. 交给检验科核对的内容

  1. 是医院来取，还是仪器主动发。主动发要 HL7 还是 ASTM。
  2. LIS 的 IP、端口，仪器的 IP。来取时，医院要能访问仪器的取数端口。
  3. 中文用 UTF-8 还是 GBK。
  4. 项目代码使用 AA_60、AA_180、AA_END、AA_MAX（以及 ADP、EPI、COL、RIS）。最大聚集率看 _MAX。
  5. 样本号、条码、姓名、审核医生是否对得上。
  6. 先做一份已知结果的样本，在 LIS 里核对 60 秒、180 秒和最大聚集率。
结果字段是固定的。不同医院只改变连接方式和消息外壳。LIS 下发医嘱到仪器，需要医院提供消息样例后再增加，不影响现在的结果上传。
