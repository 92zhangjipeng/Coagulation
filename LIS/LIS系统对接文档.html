📡 概述

仪器提供标准 HTTP RESTful API，LIS 系统可通过 GET 请求获取患者检测结果、曲线数据及自动生成的聚集曲线图片。服务地址：http://<仪器IP>:8080，数据格式 JSON，短连接模式。

✨ 新增特性： 动态配置接口、曲线图片 HTTP 直链 + Windows 网络共享路径 (UNC) 统一共享名 suoweiCurves_images，图片自动生成与定期清理。

🔗 接口一览

接口方法说明
/v1/healthGET健康检查
/v1/configGET获取图片URL前缀、共享前缀、保留天数
/v1/samplesGET按日期范围查询样本列表
/v1/sample/{sampleId}GET样本完整信息 + 曲线图片路径
/v1/sample/{sampleId}/curvesGET原始曲线数据点
/v1/sample/{sampleId}/curves.pngGET直接返回 PNG 曲线图片

⚙️ 2. 获取服务配置 (v1.1 新增)

GET /v1/config
{
  "curve_image_url_prefix": "http://192.168.3.106:8080/v1/sample/",
  "curve_image_share_prefix": "\\\\192.168.3.106\\suoweiCurves_images",
  "retention_days": 60
}

curve_image_share_prefix 为 Windows UNC 共享前缀，拼接样本ID + .png 即可获得完整共享路径；retention_days 表示图片保留天数。

📄 4. 获取单个样本完整信息 (含曲线图片访问路径)

GET /v1/sample/{sampleId}

sampleId 格式： 12位 (YYYYMMDD+4位序号) 或 13位 (末尾 F 表示复查) ，如 202605200001 或 202605200001F。

{
  "code": 200,
  "data": {
    "sample_id": "202605200001",
    "patient_name": "李丽",
    "gender": "女",
    "age": 52,
    "results": { "AA": "78%", "ADP": "82%", "EPI": "65%", "COL": "90%", "RIS": "70%" },
    "analysis_parameters": {
      "AA": { "AUC": 124.5, "MaxSlope": 8.2, "TMA": 120.3, "Lag": 45.0, "Adhesion": 92.1 }
    },

✅ curve_image_url – 通过 HTTP 直接展示图片 (img 标签或浏览器访问)
✅ curve_image_path – Windows 网络共享 UNC 路径，LIS 可直接拷贝文件或集成打开。

🖼️ 6. 获取曲线图片 (PNG)

GET /v1/sample/{sampleId}/curves.png

直接返回 image/png 格式图片。若曲线数据缺失或生成失败，返回 404 JSON 错误。

# 示例：浏览器或 curl 调用
curl http://192.168.3.106:8080/v1/sample/202605200001/curves.png --output curve.png

🔧 曲线图片网络共享访问 (Windows)

仪器程序启动时会自动将图片目录 ./suoweiCurves_images 共享为名称 suoweiCurves_images，并设置 Everyone 读取权限。LIS 端通过 \\仪器IP\suoweiCurves_images\样本号.png 即可访问。

💡 自动共享失败时手动步骤：
1️⃣ 以管理员身份运行程序（推荐）；
2️⃣ 若手动配置：右键 suoweiCurves_images 文件夹 → 属性 → 共享 → 高级共享 → 共享名 suoweiCurves_images，权限 Everyone 读取；
3️⃣ NTFS 安全页添加 Everyone 读取权限；
4️⃣ 防火墙开启“文件和打印机共享”。

🔄 推荐对接流程

  1. 启动时调用 /v1/config：缓存 curve_image_url_prefix 和共享前缀，动态构建完整图片地址。
  2. 周期拉取 /v1/samples：每 1-5 分钟获取当天样本列表，检测新样本。
  3. 获取详情 /v1/sample/{id}：存储基础数据、结果参数，并保存 curve_image_url / curve_image_path 供界面展示。
  4. 展示曲线图片：LIS 界面可直接使用 curve_image_url（需要 LIS 客户端能访问仪器 HTTP）或通过 UNC 路径复制图片到本地显示。
  5. （可选）原始曲线：如需自定义绘图，调用 /curves 获取数据点。

🛠️ 故障排除

现象可能原因解决方法
连接被拒绝服务未启动 / 端口错误 / 防火墙拦截确认仪器程序运行；netstat -ano | findstr 8080；关闭防火墙测试
curve_image_path 无法打开共享未配置 / 权限不足检查 \\仪器IP\suoweiCurves_images 是否能访问；以管理员身份重启程序或手动共享；检查防火墙“文件和打印机共享”
图片返回 404样本无曲线数据 / 图片尚未生成调用 /v1/sample/{id} 时会触发生成，再次请求 PNG 即可；确认数据库中存在曲线数据
返回空数据列表日期区间无样本 / 数据库为空确认仪器已做测试，日期格式正确

📦 测试示例 (PowerShell)

# 健康检查
Invoke-WebRequest -Uri http://127.0.0.1:8080/v1/health -UseBasicParsing

# 获取配置
Invoke-WebRequest -Uri http://127.0.0.1:8080/v1/config -UseBasicParsing

# 查询样本
Invoke-WebRequest -Uri "http://127.0.0.1:8080/v1/samples?start_date=2026-05-28&end_date=2026-05-28"

# 获取样本详情 & 图片链接
$sample = Invoke-WebRequest -Uri http://127.0.0.1:8080/v1/sample/202605280001
$sample.Content | ConvertFrom-Json | Select-Object -ExpandProperty data | Select-Object curve_image_url

# 下载曲线图片
Invoke-WebRequest -Uri "http://127.0.0.1:8080/v1/sample/202605280001/curves.png" -OutFile "D:\curve.png"
